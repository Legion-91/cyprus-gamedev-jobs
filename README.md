# cyprus-gamedev-jobs

Парсер списка кипрских геймдев компаний из GameDevMap.

Сейчас проект делает первый этап:

- загружает список компаний по фильтру Cyprus
- вытаскивает название, тип, город, страну и официальный сайт
- сохраняет данные в `data/studios.json` и `data/studios.csv`
- может запускаться вручную через GitHub Actions
- автоматически запускается раз в сутки

## Ручной запуск с телефона

1. Открой репозиторий на GitHub.
2. Перейди во вкладку `Actions`.
3. Выбери `Scrape Cyprus studios`.
4. Нажми `Run workflow`.
5. После завершения обновятся файлы в папке `data`.

## Следующий этап

Для каждой студии найти страницу Careers или внешний ATS и начать собирать вакансии.
